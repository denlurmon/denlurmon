# Den Lurmon Underground (Static Site)

Статичный сайт для артиста, адаптированный для хостинга на GitHub Pages.

## Как запустить:

1. **Создайте репозиторий на GitHub.**
   Назовите его `ВАШ_ЛОГИН.github.io` (например, `denlurmon.github.io`), если хотите, чтобы сайт открывался по адресу `https://denlurmon.github.io`.

2. **Загрузите файлы.**
   Залейте в корень репозитория все файлы из этого архива:
   - `index.html`
   - `songs.html`
   - `news.html`
   - `contacts.html`
   - `style.css`

3. **Видео и Музыка:**
   - Переименуйте ваше фоновое видео в `video-bg.mp4` и тоже загрузите в корень репозитория.
   - В файле `songs.html` замените цифры в ссылке Яндекс.Музыки (`...album/123456`) на ID вашего альбома.

4. **Настройка GitHub Pages:**
   Зайдите в настройки репозитория (Settings) -> Pages.
   В разделе "Branch" выберите ветку `main` (или `master`) и корень (`/ (root)`). Сохраните.
   Через 1-2 минуты сайт будет доступен.

5. **Свой домен (если нужно):**
   Если вы хотите использовать свой домен (например, `denlurmon.ru`):
   - Купите домен у регистратора.
   - В настройках DNS регистратора создайте запись типа **A**, указывающую на IP-адрес GitHub Pages: `185.199.108.153` (и еще три: .109, .110, .111).
   - В корне репозитория создайте пустой файл с названием `CNAME`.
   - Внутри файла `CNAME` напишите одну строку: `ваш-домен.ru`.

## Важно:
GitHub Pages — это статика. Новости здесь — это просто текст в HTML-коде. Чтобы добавить новость, нужно отредактировать файл `news.html` и заново загрузить его в репозиторий.
